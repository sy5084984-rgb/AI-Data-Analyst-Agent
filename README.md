# AI Data Analyst Agent 📊

A Python-based data analysis dashboard built using Streamlit, Pandas, NumPy, and Matplotlib.

## 🚀 Features

* Upload CSV and Excel files
* View dataset overview and statistical summaries
* Detect missing values and duplicate rows
* Create charts and visualizations
* Analyze numerical and categorical data
* Compare data by categories
* Download analysis reports

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Streamlit
* OpenPyXL

## ▶️ How to Run

1. Install Python.

2. Install the required libraries:

   `pip install streamlit pandas numpy matplotlib openpyxl`

3. Open a terminal in the project folder.

4. Run the application:

   `python -m streamlit run app.py`

5. Open the local URL shown in the terminal.
